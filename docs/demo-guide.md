# คู่มือสาธิต PairEval Demo (5–10 นาที)

## เตรียมก่อนเริ่มจับเวลา

1. แตก `delivery/PairEval-Demo-source.zip` ไปพาธภาษาอังกฤษ เปิดโฟลเดอร์ที่มี `package.json` ใน terminal และตรวจว่าใช้ Node.js 24 ขึ้นไป รัน `npm ci` แล้ว `npm run build` ครั้งแรกบนเครื่องนั้น
2. ปิด server เดิม แล้วรัน `npm run seed:reset` เพื่อเริ่มด้วยข้อมูลใหม่ จากนั้นรัน `npm run start -- -p 3100` และเปิด `http://localhost:3100`
3. เตรียม [รายชื่อสังเคราะห์ 21 คน](../examples/roster-demo-21.csv) ไว้สำหรับ upload: 3 กลุ่ม × 7 คน มี `student-01@demo.invalid` อยู่ในชุด ไม่ใช้ข้อมูลนักศึกษาจริง
4. เปิด terminal อีกหน้าต่างในโฟลเดอร์เดียวกันสำหรับ `npm run demo:prepare -- <assignment-id>` **หลัง** กดสร้างคู่สำเร็จ ID ของงานคือข้อความท้าย URL ของหน้างาน คำสั่งนี้จะเลือกนักศึกษาที่ได้รับทั้ง Group และ Individual อย่างน้อยอย่างละ 2 คู่ และบันทึกคำตอบสังเคราะห์ของผู้ประเมินคนอื่นเป็น submission จริงโดยเว้นบัญชีที่เลือกไว้ แสดงอีเมลให้ใช้เข้า Demo นักศึกษา
5. เตรียม Microsoft Excel เพื่อเปิด CSV ที่ดาวน์โหลดจากแอป

`seed:reset` ล้างฐานข้อมูลเดโมเดิมทั้งหมด Session เก่าจะใช้ไม่ได้ ให้เลือกบัญชีใหม่ที่หน้าแรก หาก Windows แจ้งว่า SQLite ถูกใช้งาน ให้หยุด server ก่อนแล้ว reset ใหม่
หากงานนั้นมีนักศึกษาส่งคำตอบครบทุกคนแล้ว `demo:prepare` จะแจ้งว่าไม่พบบัญชีที่ยังไม่ส่ง ให้เริ่มจาก `seed:reset` สำหรับการซ้อมรอบใหม่

| เวลาโดยประมาณ | สิ่งที่ทำ | ผลที่ควรเห็น |

ถ้าเวลาเหลือน้อย ให้ซ้อมข้อผิดพลาดก่อนเดโมจริง: วาง CSV ที่มีอีเมลซ้ำในหน้า “สร้างห้อง + CSV” แล้วกดตรวจตัวอย่าง จะเห็นแถวที่ผิดและสร้างห้องไม่ได้ จากนั้น upload ไฟล์ถูกต้องต่อทันที หลีกเลี่ยงการเพิ่ม P1 ในช่วงสาธิต

## เปิด CSV ใน Microsoft Excel บน Windows

วิธีนี้ตรวจจริงกับ CSV ที่ดาวน์โหลดจาก PairEval-Demo บนเครื่อง Windows ปัจจุบัน:

1. ใน Excel เลือก **File → Open → Browse** แล้วเลือกไฟล์ `*-scores.csv`
2. ถ้า Text Import Wizard เปิดขึ้นมา ให้เลือก **Delimited** และ File origin **65001: Unicode (UTF-8)**; เลือก “My data has headers” แล้วกด Next
3. ยกเลิก **Tab**, เลือก **Comma** เพียงตัวเดียว และให้ Text qualifier เป็น `"`; ตรวจ preview ว่าหัวตาราง `assignment`, `group`, `student_id`, `student` แยกเป็นคนละคอลัมน์ แล้วกด Next → Finish
4. ถ้าข้อความถูกตัดเพราะคอลัมน์แคบ ให้คลิกมุมซ้ายบนของตารางเพื่อเลือกทั้งหมด แล้วดับเบิลคลิกเส้นคั่นหัวคอลัมน์ A/B เพื่อ AutoFit ทุกคอลัมน์

Excel เครื่องที่ทดสอบเดา “Fixed width” เองในครั้งแรก ซึ่งรวมหลายคอลัมน์ผิด จึงต้องเลือก Delimited/Comma ตามขั้นตอนนี้ เมื่อเปิดถูกต้องเห็นภาษาไทย เช่น `นักศึกษา day6-17`, 21 แถวนักศึกษา และคอลัมน์ `group_score`, `individual_score`, `total` แยกกัน แถบ “Possible Data Loss” ของ Excel เป็นคำเตือนเรื่องการ **บันทึก** กลับเป็น CSV; การเปิดอ่านไม่ได้ทำให้ข้อมูลคะแนนเปลี่ยน

## กติกาคะแนนที่อธิบายระหว่างเดโม

- ผู้ประเมินเลือก 1–6 ให้แต่ละคู่: 1 ให้ฝั่งแรกทั้งหมด, 6 ให้ฝั่งหลังทั้งหมด; ค่าเฉลี่ยจากคำตอบที่ Submit แล้วของผู้ประเมินที่ได้รับคู่ถูกนำไปคำนวณตามน้ำหนักเกณฑ์
- Group เป็นคะแนนตั้งต้นของกลุ่ม; Individual normalize ภายในกลุ่ม; คะแนนส่วนตัวคูณสัดส่วนคู่ที่นักศึกษาคนนั้น Submit แล้วในแต่ละชนิด ตามสูตรเดโมใน Plan.md §3 ข้อ 8–10
- ใช้ revision ล่าสุดที่ Submit แล้วเท่านั้น Draft ไม่คิดคะแนน และ Re-submit เก็บ revision เดิมไว้
- หากข้อมูลของคู่/เกณฑ์ยังไม่พอแสดง `NO_DATA` ตามกรณี ไม่เติมคะแนนสมมติ

## ขอบเขตส่งมอบและข้อจำกัด

| ส่วน | สถานะเดโม |
|---|---|
| ห้อง/CSV/งาน/การตรวจรูปแบบ | ทำงานจริงกับข้อมูลสังเคราะห์ |
| จัดคู่ Group/Individual, target 5, ห้าม self-evaluation | ทำงานจริง; ถ้าจัดไม่ได้ปฏิเสธทั้งงาน |
| Draft, Submit/Re-submit, deadline, session/เจ้าของคู่ | ทำงานจริงใน Demo; ไม่มีระบบยืนยันตัวตนผู้ใช้จริง |
| คะแนน/รายงาน/My Score/CSV | คำนวณจาก submission ที่บันทึกในระบบ; นักศึกษาเห็นเฉพาะคะแนนตน |
| P1: อาจารย์ร่วม, เพิ่ม evaluator, อาจารย์ประเมิน, เปลี่ยนกลุ่ม/จัดคู่ใหม่, Raw Pairs, Excel export, notification | ยังไม่ทำ backend; หน้าที่มีเป็นป้ายบอกสถานะ |

ข้อมูลเพื่อนที่คำสั่งเตรียมให้เป็น **คำตอบสังเคราะห์** แต่เป็น submission revision จริง คะแนนไม่ฝังใน seed/UI/CSV. บัญชี Demo เลือกได้จากหน้าแรกโดยไม่มีรหัสผ่าน จึงห้ามใช้ข้อมูลจริงหรือเผยแพร่เป็นระบบให้คะแนนจริง. CSV export คือไฟล์ `.csv` ที่ Excel อ่านได้ ไม่ใช่ Excel export `.xlsx`. เครื่องนำเสนอจริงเป็นอีกเครื่องและต้องซ้อมขั้นตอนติดตั้ง/เปิดแอป/Excel ซ้ำบนเครื่องนั้นก่อนอ้างว่าผ่าน Definition of Done
