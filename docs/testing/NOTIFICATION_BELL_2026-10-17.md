## API ที่เปลี่ยน

`GET /api/full-system/notifications` คง `data` เป็น array และฟิลด์เดิม เพิ่ม `classroomName`, `assignmentTitle` ต่อรายการ และ `meta: { unreadCount, totalCount }` ตัวเลขนับก่อนจำกัด 100 รายการ

`POST` endpoint เดิม:

| Body | ผลสำเร็จ |
|---|---|
| `{ "id": "notification-uuid" }` | `{ "data": { "read": true } }` ตามเดิม |
| `{ "all": true }` | `{ "data": { "read": true, "updatedCount": 105 } }` โดยตัวเลขขึ้นกับจำนวนที่เปลี่ยนจริง |

ส่ง `id` และ `all` พร้อมกันหรือ `all` ที่ไม่ใช่ true ตอบ 422; ID ที่ไม่ถูกต้อง/ไม่มีสิทธิ์ตอบ 404; คงการตรวจ session, Privacy Notice และ same-origin สำหรับ POST

การแสดง นับ และบันทึกอ่านใช้เงื่อนไขสิทธิ์เดียวกัน: ผู้รับ สมาชิกที่ active บทบาทที่รับเหตุการณ์ได้ ห้อง active รุ่นงานปัจจุบัน สถานะงาน และโดเมนอีเมล เหตุการณ์ `SCORE_FINALIZED` ต้องเป็นงานที่ Final แล้ว ส่วน Owner ยังคงรับเฉพาะ `FINALIZE_REVIEW_REQUIRED` ตามระบบเดิม
