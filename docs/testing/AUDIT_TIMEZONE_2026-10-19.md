# เวลาประวัติการทำรายการตามห้องเรียน — 19 ตุลาคม 2026

## สิ่งที่เปลี่ยน

- API `GET /api/full-system/assignments/{id}/audit` เพิ่ม `meta.timezone` จากห้องของงานที่ผ่านการตรวจสิทธิ์แล้ว คงรายการ `data` และ `occurredAt` เป็น ISO UTC เดิม
- ตารางประวัติแปลงเวลาเพื่อแสดงตามห้อง เช่น `เวลา (Asia/Bangkok)` หรือ `เวลา (UTC)` ด้วยรูปแบบภาษาไทย พร้อมวินาที เก็บค่า UTC ต้นฉบับไว้ใน `<time datetime>`
- เวลาอัปเดตคะแนนในหน้ารายงานใช้เขตเวลาเดียวกัน หากโหลดเขตเวลาไม่ได้จะแจ้งชัด ไม่เดาเป็นเวลาของ browser
- ไม่เปลี่ยน audit ที่บันทึกไว้ ไม่เพิ่ม migration และไม่ขยายสิทธิ์อ่านประวัติ
