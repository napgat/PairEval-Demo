# แก้ปุ่มยืนยันนำเข้ารายชื่อของห้องที่ยังไม่มีงาน — 19 ตุลาคม 2026

## สาเหตุและการแก้

CSV 17 คนที่เพิ่มนักศึกษาคนใหม่ในกลุ่ม 4 ใช้รูปแบบที่ระบบรองรับ Preview สำเร็จแล้ว แต่เครื่องมือรายชื่อในหน้าจัดการงานเคยเปิดปุ่มนำเข้าเฉพาะเมื่อเลือกงาน DRAFT ทำให้ห้องใหม่ที่ยังไม่มีงานกดยืนยันไม่ได้

แก้เงื่อนไขให้ตรวจงานทั้งหมดในห้อง: หากยังไม่มีงานหรือมีเฉพาะ DRAFT/ARCHIVED ให้ใช้ปุ่มได้หลัง preview สำเร็จ โดยไม่ต้องเลือกงานก่อน หากมีงานสถานะอื่น ปิดปุ่มและแสดงคำอธิบาย Backend ยังคงตรวจสิทธิ์ digest/version และการมีงานเผยแพร่เหมือนเดิม

## ผลตรวจจริง

- ห้อง fixture เริ่ม 16 คน/4 กลุ่ม ไม่มีงาน → กรอก CSV 17 คนผ่าน GUI → preview เพิ่ม 1/คงเดิม 16 → กดยืนยันจริง API 200 และรายชื่อเป็น 17 คน
- ห้องมี DRAFT แต่ยังไม่เลือกงาน: ปุ่มเปิดหลัง preview; แก้ข้อความ CSV อีกครั้งจะล้าง preview และปิดปุ่มจนตรวจใหม่
- ห้องมีทั้ง DRAFT และ OPEN: แม้เลือก DRAFT ปุ่มยังปิดและมีเหตุผล; เรียก import ตรงยังตอบ 409 `ASSIGNMENT_PUBLISHED`
- Tests 109/109, typecheck, lint และ build ผ่าน ไม่มี page error ใน GUI รอบนี้ ลบ fixture ของการทดสอบแล้ว ห้อง fixture คงเหลือ 0

ทดสอบเฉพาะห้อง/บัญชีสังเคราะห์ที่สร้างแยก ไม่กดยืนยัน CSV แทนผู้ใช้ในห้องที่กำลังซ้อม สคริปต์และผลส่วนตัวอยู่ใน `.verification/roster-no-assignment-20261019.mjs` และ `.verification/roster-no-assignment-20261019/results.json` ของชุด local ใหม่ ไม่รวม runtime/credential ใน Git

## ลองซ้ำ

รีเฟรชหน้าจัดการงาน → กาง **จัดการรายชื่อนักศึกษาและกลุ่ม** → วาง CSV ใหม่ → **ตรวจข้อมูลและดูการเปลี่ยนกลุ่ม** → ตรวจจำนวนเพิ่ม/ย้าย/คงเดิม → **ยืนยันนำเข้ารายชื่อ**

หากใช้หน้า **รายชื่อและกลุ่ม** ให้กาง **นำเข้าหรือปรับกลุ่มด้วยไฟล์ CSV** → **ตรวจข้อมูล** → **ยืนยันนำเข้ารายชื่อ** ตามเดิม ไม่ใส่เครื่องหมายคำพูดครอบ CSV ทั้งก้อน
