# ติดตั้งและทดลอง PairEval บนเครื่องเพื่อน

## สิ่งที่ต้องเตรียม

- Windows x64 และ Node.js **24.x** พร้อม npm ตรวจด้วย `node --version` และ `npm --version`
- Git หากจะ clone; ถ้าไม่ใช้ Git ให้ดาวน์โหลด ZIP ของสาขา **main** จาก GitHub แล้วแตกไฟล์
- อินเทอร์เน็ตขณะ `npm ci` และ build ครั้งแรก (รวมการดาวน์โหลดฟอนต์)
- โฟลเดอร์ชื่อภาษาอังกฤษตลอดพาธ เช่น `C:\PairEvalDemo` หรือ `C:\Projects\PairEvalDemo` หลีกเลี่ยง OneDrive และพาธภาษาไทยในรุ่นนี้

ตัวเปิดบริการตรวจบน Windows x64 เท่านั้น macOS/Linux ต้องปรับตัวเปิดก่อน จึงยังไม่อ้างว่าใช้คำสั่งนี้ได้ครบ ขั้นตอนนี้ใช้ข้อมูลสมมติ ไม่ต้องมี Google OAuth, Neon, Vercel, Docker หรือ PostgreSQL ที่ติดตั้งแยก

## 1. ดาวน์โหลดและติดตั้ง

รีโปเป็น **Private** ณ วันที่จัดชุดนี้ เจ้าของต้องเพิ่มบัญชี GitHub ของเพื่อนให้เข้าถึงรีโปและเพื่อนตอบรับคำเชิญก่อน จากนั้นใช้บัญชี GitHub ของเพื่อนเอง clone ไม่ใช้ token หรือรหัสผ่านของเจ้าของ หากไม่ให้สิทธิ์ GitHub ให้เจ้าของดาวน์โหลด source ZIP ของ **main** และส่งไฟล์ให้เพื่อนแทน

เปิด PowerShell:

```powershell
git clone https://github.com/napgat/PairEval-Demo.git C:\PairEvalDemo
cd C:\PairEvalDemo
node --version
npm ci
npm run build
```

ต้องอยู่ในโฟลเดอร์ที่มี `package.json` ถ้าใช้ ZIP ให้ข้าม `git clone` และเข้าโฟลเดอร์ที่แตกแล้ว ไม่ต้องรัน `npm run seed` หรือ `seed:reset` เพราะเป็นของ SQLite Demo เดิม

## 2. เปิดใช้งาน

ดับเบิลคลิก `Open-PairEval-Demo.cmd` หรือรัน:

```powershell
.\Open-PairEval-Demo.cmd
```

รอเตรียมฐานข้อมูลและห้องสาธิตครั้งแรก แล้วเปิด **http://localhost:3103** ถ้าหน้าเว็บยังไม่ขึ้น ให้รอข้อความว่าบริการพร้อมก่อน ห้ามนำหน้าเลือกบทบาทนี้ไปเปิดรับผู้ใช้จริง

| บริการ | ที่อยู่ | หน้าที่ |
|---|---|---|
| ตัวเลือกบทบาท | http://localhost:3103 | เลือกบัญชีสังเคราะห์โดยไม่ใช้ Google |
| แอป | http://localhost:3101/full-system | ห้อง งานประเมิน คะแนน และรายงาน |
| PostgreSQL | `127.0.0.1:55432` | ข้อมูลและ audit ในเครื่อง ไม่ต้องเปิดด้วย browser |

ตัวเปิดสร้าง `.env.local` และ `.verification/` เอง ห้ามคัดลอกไฟล์สองส่วนนี้จากเพื่อนหรือส่งกลับเข้า Git ข้อมูลแต่ละเครื่องแยกจากกัน การเลือกบัญชีใหม่ใน browser เดียวกันเปลี่ยนบทบาทของแท็บอื่นด้วย หากต้องการดูอาจารย์–นักศึกษาคู่กัน ให้ใช้ browser คนละ profile หรือหน้าต่างส่วนตัวแยกกัน

## 3. ลองงานหลัก

เลือก **อาจารย์เจ้าของห้อง** → ห้อง `PairEval · สาธิต PRD v2.0` → เปิดงาน `ประเมินผลงานโครงงาน — ข้อมูลจำลอง` จากนั้นทำตาม [รายการทดสอบ](TRY_IT.md)

งานหลักเปิดรับ 7 วันนับจากสร้างชุดครั้งแรก ข้อมูลมี 16 นักศึกษา/4 กลุ่ม และคำตอบบางส่วนให้ดูรายงานได้แล้ว นักศึกษาคนที่ 1 ใช้ลองร่างและส่งคำตอบเองได้

## 4. เตรียม Final และอุทธรณ์ (ทางเลือก)

ขณะบริการเปิดอยู่ ให้เปิด PowerShell อีกหน้าต่างในโฟลเดอร์เดิม:

```powershell
npm run demo:prepare-final
```

คำสั่งสร้างงาน `ตัวอย่างปิดงาน · คะแนนและอุทธรณ์` พร้อมคำตอบสังเคราะห์ 32 submissions กำหนด deadline อีก **5 นาทีจริง** นับจากเตรียม รอเวลาที่แสดงก่อนกด Final ผ่าน UI การเรียกซ้ำไม่ reset งานที่เตรียมเสร็จแล้ว ไม่เปลี่ยนนาฬิกาหรือแก้ SQL เพื่อข้ามกำหนดส่ง

เครื่องใหม่ไม่ได้รับคะแนน/อุทธรณ์ที่ผู้พัฒนาเคยซ้อมไว้ ต้องทำ flow เอง คะแนนและ ID อาจต่างจากภาพรายงานเก่า ไม่ใช้ตัวเลข 16.94 เป็นคำตอบตายตัวของทุกเครื่อง

## 5. ปิดและเปิดใหม่

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop-PairEval-Demo.ps1
```

คำสั่งนี้ปิดบริการที่ตัวเปิดชุดนี้สร้างและเก็บข้อมูลไว้ เมื่อเปิด `.cmd` อีกครั้ง คำตอบ คะแนน และประวัติยังอยู่ เปิดครั้งละ **หนึ่งโฟลเดอร์** เพราะทุกชุดใช้ port เดียวกัน

## 6. อัปเดตรุ่นภายหลัง

หยุดบริการก่อน ตรวจ `git status` ว่าไม่มี source ที่แก้ค้าง หากมีให้เก็บงานและตรวจ diff ก่อน ไม่ใช้ `reset --hard` หรือ `clean` เพื่อล้างทิ้ง

```powershell
git pull --ff-only origin main
npm ci
npm run build
.\Open-PairEval-Demo.cmd
```

ตัวเปิดลง migration ของ **ฐาน local สาย v2.0 นี้** ให้ หากเปลี่ยนจาก branch v2.1 หรือฐาน staging เดิม ห้ามใช้ขั้นตอนอัปเดตนี้ทับตรง ๆ เพราะ migration 013–015 ต่างกัน ให้ทดลองในโฟลเดอร์/ฐาน local ใหม่

## เมื่อเปิดไม่ขึ้น

| อาการ | ทำอย่างไร |
|---|---|
| หา `node`/`npm` ไม่พบ หรือเวอร์ชันไม่ใช่ 24 | ติดตั้ง Node.js 24 แล้วเปิด PowerShell ใหม่ |
| PowerShell ไม่ยอมเรียก `npm.ps1` | ใช้ `npm.cmd ci`, `npm.cmd run build` หรือเปิด Command Prompt; ไม่ต้องลดนโยบายความปลอดภัยทั้งเครื่อง |
| หา `package.json` ไม่พบ | เข้าโฟลเดอร์โปรเจกต์จริงก่อน |
| แจ้งไม่มี verified build | รัน `npm ci` และ `npm run build` ให้สำเร็จ |
| PostgreSQL เปิดไม่ขึ้นในพาธภาษาไทย | หยุดชุดเดิมและติดตั้งใหม่ในพาธภาษาอังกฤษ อย่าย้ายฐานที่กำลังเปิดอยู่ |
| port ถูกใช้งาน/มี demo อีกชุด | หยุดจาก `Stop-PairEval-Demo.ps1` ในโฟลเดอร์ที่เปิดชุดนั้น ไม่ปิด process ของโปรแกรมอื่นแบบสุ่ม |
| ลิงก์ 3101 ขึ้น Google หรือยังไม่ได้ login | เข้า 3103 แล้วเลือกบทบาทก่อน ชุดนี้ไม่ต้องใช้ปุ่ม Google |
| Final ถูกปฏิเสธ | ตรวจว่าเป็น Owner, รอ deadline ของทั้งสองด้าน และมีผลคำนวณล่าสุด |
| งานหลักหมดเขตหลังผ่านไป 7 วัน | ดูข้อมูลเดิมต่อได้ หรือสร้างงานใหม่ผ่าน UI; หากต้องการเริ่มชุดสาธิตใหม่ให้ใช้โฟลเดอร์ใหม่หลังหยุดชุดเดิม |
| เปิดแล้วค้าง/หน้าว่าง | ดู `.verification/v20-20261015/launcher/*.err.log` แล้วส่งเฉพาะข้อความที่ตัด secret ออก พร้อมขั้นตอนเกิดปัญหา |

ไม่ส่ง `.env.local`, `.verification`, DB หรือ backup/key ให้ผู้ตรวจ อ่าน [รูปแบบแจ้งปัญหา](TRY_IT.md#รายงานผลกลับ) ก่อนแนบไฟล์
