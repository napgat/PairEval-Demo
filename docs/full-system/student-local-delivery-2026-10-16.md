## ติดตั้งครั้งแรก

1. แตก ZIP ไปพาธภาษาอังกฤษ เช่น `E:\PairEval-Student-Demo` บนเครื่องนี้ embedded PostgreSQL เปิดจากพาธภาษาไทยไม่สำเร็จ
2. ติดตั้ง Node.js 24 และเปิด terminal ในโฟลเดอร์ที่มี `package.json`
3. รัน `npm ci` แล้ว `npm run build` ครั้งแรกต้องใช้อินเทอร์เน็ตดาวน์โหลด dependency
4. ดับเบิลคลิก `Open-PairEval-Demo.cmd` แล้วเปิด <http://localhost:3103>
5. ตัวเปิดสร้าง `.env.local`, PostgreSQL operational/audit แยก และข้อมูลสังเคราะห์ใหม่ในเครื่อง ไม่ต้องคัดลอก env หรือรัน SQLite seed
6. เตรียมงานปิดรับเพิ่มเติมด้วย `npm run demo:prepare-final` ขณะบริการเปิดอยู่ ครั้งแรกกำหนด deadline อีก 5 นาทีตามเวลาจริง รอให้พ้นเวลาที่คำสั่งแสดงก่อน Finalize

ใช้ port 3101 (แอป), 3103 (ตัวเลือกบทบาท), 55432 (ฐานข้อมูล) เฉพาะ loopback เปิดชุดสาธิตครั้งละหนึ่งโฟลเดอร์เพื่อไม่ใช้ port/ฐานข้อมูลผิดชุด

ปิดด้วย:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop-PairEval-Demo.ps1
```

การเปิดใหม่เก็บห้อง คำตอบ revision คะแนน และคำอุทธรณ์เดิมไว้ การรัน `demo:prepare-final` ซ้ำไม่ reset งานที่เตรียมเสร็จแล้ว ไม่มี HTTP endpoint สำหรับ reset ชุดนี้

## ลำดับนำเสนอ 15–20 นาที

เตรียม `demo:prepare-final` และรอ 5 นาทีก่อนเริ่ม เพื่อไม่เสียเวลาระหว่างนำเสนอ

1. **นาที 0–3 — Owner:** เลือกห้อง → งานหลัก → อธิบายคะแนนกลุ่ม 15/รายบุคคล 5 เกณฑ์กลุ่ม 60/40 และรายบุคคล 100 ดู seed/coverage และเปิดรายงาน
2. **นาที 3–7 — นักศึกษา:** กลับตัวเลือกบทบาท → นักศึกษาคนที่ 1 → งานหลัก → เปิดผลงานจำลอง → ตอบ Group และ Individual → บันทึกร่าง → reload → ส่ง/แก้ไขส่งใหม่ → ดูคะแนนเฉพาะตน งานนี้อาจมีคำตอบเดิมจากการซ้อมแล้ว ให้สาธิต revision ใหม่ตามจริง
3. **นาที 7–10 — Owner:** งานหลัก → รายงาน → คำนวณ Interim ใหม่ → ดู 4 tabs และค่า p/M → ดาวน์โหลด CSV/XLSX
4. **นาที 10–13 — Owner/นักศึกษา:** เลือกงานปิดงาน → คำนวณ Interim → ยืนยันผลคะแนนหลัง deadline → เปลี่ยนเป็นนักศึกษา → เปิดคะแนน Final ผ่านการแจ้งเตือน → ยื่นอุทธรณ์พร้อมเหตุผลอย่างน้อย 20 ตัวอักษร
5. **นาที 13–17 — Owner:** งานปิดงาน → รายงาน → ระบุเหตุผลเปิดคะแนนใหม่อย่างน้อย 10 ตัวอักษร → เปิดคะแนนให้แก้ไข → Override ด้านรายบุคคล นักศึกษาคนที่ 1 เป็น 4.50 พร้อมเหตุผล → ยืนยัน Final อีกครั้ง → เลือกคำอุทธรณ์และตอบรับพร้อมเหตุผล
6. **นาที 17–20 — นักศึกษา/บทบาทอื่น:** ตรวจคะแนนใหม่และคำตอบอุทธรณ์ ผู้สอนร่วมดูรายงานแต่ไม่มีปุ่ม Final/Reopen; TA ดูรายชื่อ ปิดและเปิดตัวสาธิตใหม่เพื่อแสดงว่าข้อมูลคงอยู่

หากงานที่สอง Final แล้ว ให้แสดงประวัติ/ผลเดิม และ Reopen พร้อมเหตุผลเพื่อซ้อมรอบใหม่โดยไม่ลบประวัติ หากอุทธรณ์ปิดแล้วสามารถยื่นรอบใหม่ตามกติกาและภายในหน้าต่างเวลา อย่าอ้างว่าการซ้อมทุกครั้งเริ่มจากฐานว่าง
