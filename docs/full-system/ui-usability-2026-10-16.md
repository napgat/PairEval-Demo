## สิ่งที่เปลี่ยน

- เมนูและบัญชีอยู่ตำแหน่งเดียวกันทุกหน้า ใช้ชื่อที่มีในบัญชีแทนชื่ออีเมลภายใน เพิ่ม skip link และนำทางภายในด้วย Next Link
- ค้นหาห้องเรียนและงานได้ หน้างานนักศึกษากรองตามช่วงใช้งาน ปุ่มแสดงตามสถานะและ deadline จริง
- อาจารย์เปิดงานแล้วเข้ารายงานได้ทันที ไม่ต้องเลื่อนผ่านฟอร์มยาว การสร้างงานเลื่อนไปฟอร์มและโฟกัสชื่อให้อัตโนมัติ
- พับรายละเอียดการตั้งค่า สูตรคะแนน ลิงก์รายชิ้น การจับคู่ การส่งออกคำตอบรายคู่ และประวัติการทำรายการ แทนการแสดงทุกส่วนพร้อมกัน
- รายงานใช้ชื่อเกณฑ์/ผลงานแทน UUID ในตารางความครอบคลุม แปลสถานะและหมายเหตุหลักเป็นไทย และสลับแท็บด้วยปุ่มลูกศร/Home/End ได้
- นักศึกษาเห็นสถานะคะแนนและประวัติคำขอทบทวนแยกชัดเจน มีข้อความเมื่อกำลังส่งคำขอและป้องกันการกดซ้ำ
- เปลี่ยนกล่องยืนยันส่งคำตอบ/ยืนยันคะแนนเป็น dialog ในหน้า รองรับ Esc, focus trap ของ native dialog และคืนโฟกัสเมื่อปิด
- ลดพื้นหลังตกแต่ง ขนาดหัวเรื่อง ระยะห่าง และกรอบซ้อน ปรับปุ่ม/ฟอร์ม/ตารางให้สอดคล้องกัน คงสีเขียวสำหรับการกระทำหลักและฟอนต์เดิม
- จอแคบใช้เมนูสองแถว ตารางเลื่อนเฉพาะในกรอบ และแถบส่งคำตอบอยู่ท้ายเนื้อหาเพื่อไม่บังคำถาม

API session เพิ่ม `displayName` จากข้อมูลผู้ใช้ที่มีอยู่เพื่อแสดงชื่อ ไม่เปลี่ยนการยืนยันตัวตนหรือสิทธิ์ ไม่มี migration ใหม่และไม่มีการเปลี่ยนสูตรคะแนน
