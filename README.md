# PairEval

ต้นแบบโครงงานนักศึกษาสำหรับประเมินผลงานแบบเปรียบเทียบเป็นคู่ อาจารย์จัดห้องเรียนและงานประเมิน นักศึกษาประเมินกลุ่ม/รายบุคคล แล้วดูคะแนนและขอทบทวนผลได้

**รุ่นปัจจุบัน: Full System ตาม PRD v2.0 สำหรับทดลองบนเครื่อง ด้วยข้อมูลสังเคราะห์** ไม่ใช่ระบบบันทึกคะแนนจริง ความพร้อมต้นแบบประมาณ **95%** ตามเกณฑ์ส่งมอบใน [สถานะโครงงาน](docs/PROJECT_STATUS.md) ส่วนที่รอคือเพื่อนติดตั้งและลองใช้งานบนเครื่องของตนเอง

## เพื่อนเริ่มตรงนี้

รีโปเป็น **Private** เจ้าของต้องให้สิทธิ์บัญชี GitHub ของเพื่อนก่อน clone หรือส่ง source ZIP ของ main ให้โดยตรง ไม่ส่ง token/รหัสผ่านของเจ้าของให้เพื่อน

ทดสอบขั้นตอนติดตั้งบน **Windows x64 + Node.js 24** ใช้โฟลเดอร์ชื่อภาษาอังกฤษ เช่น `C:\PairEvalDemo` และอินเทอร์เน็ตสำหรับดาวน์โหลดครั้งแรก ยังไม่ได้ยืนยันขั้นตอนเปิด–ปิดบน macOS/Linux

```powershell
git clone https://github.com/napgat/PairEval-Demo.git C:\PairEvalDemo
cd C:\PairEvalDemo
npm ci
npm run build
.\Open-PairEval-Demo.cmd
```

เปิด **http://localhost:3103** แล้วเลือกอาจารย์หรือนักศึกษาจำลอง ไม่ต้องเตรียม Google OAuth, Neon หรือคัดลอก `.env` จากใคร ตัวเปิดสร้าง PostgreSQL และค่าตั้งในเครื่องให้เอง เก็บข้อมูลไว้เมื่อปิด–เปิดใหม่

| ต้องการทำอะไร | อ่านไฟล์นี้ |
|---|---|
| ติดตั้ง เปิด–ปิด แก้ปัญหา และอัปเดตรุ่น | [คู่มือเริ่มใช้งาน](docs/GETTING_STARTED.md) |
| ลองเส้นทางอาจารย์–นักศึกษา และแจ้งปัญหา | [รายการทดสอบสำหรับเพื่อน](docs/TRY_IT.md) |
| ให้ AI ช่วยเปิดและทดสอบในเครื่อง | [คำสั่งเริ่มงานสำหรับ AI](docs/AI_HANDOFF.md) และ [AGENTS.md](AGENTS.md) |
| ดูฟีเจอร์ที่มี หลักฐาน และข้อจำกัด | [สถานะโครงงาน](docs/PROJECT_STATUS.md) |
| หาเอกสารออกแบบ/ผลตรวจย้อนหลัง | [สารบัญเอกสาร](docs/README.md) |

## งานตัวอย่าง

- ห้องสาธิตมีนักศึกษา 16 คนใน 4 กลุ่ม พร้อม Owner, Co-teacher และ TA
- งานหลักเปิดรับ 7 วันนับจากเตรียมครั้งแรก ใช้ลอง Group/Individual, ร่าง, ส่งซ้ำ, คะแนนระหว่างดำเนินงาน และรายงาน
- เตรียมงาน Final/อุทธรณ์แยกได้ด้วย `npm run demo:prepare-final` **หลังเปิดบริการแล้ว** รอ deadline 5 นาทีจริงก่อนยืนยันคะแนน ดูขั้นตอนในคู่มือทดสอบ

เปิดสาธิตครั้งละหนึ่งโฟลเดอร์ ใช้ port 3101, 3103 และ 55432 เฉพาะเครื่องตนเอง หยุดด้วย:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop-PairEval-Demo.ps1
```

## สำหรับผู้พัฒนา

```powershell
npm test
npm run typecheck
npm run lint
npm run build
# ทางเลือก: ติดตั้ง browser ทดสอบ แล้วตรวจหน้าหลักของชุดสาธิตที่เปิดอยู่
npx playwright install chromium
npm run test:demo-ui
```

ผลล่าสุดก่อนส่งมอบ: unit tests 88/88 ผ่าน, typecheck/lint/build ผ่าน และ GUI/Axe ชุดสาธิตเดิม 22 หน้าจอ/สถานะผ่าน รายงานแยกการตรวจเครื่องใหม่และข้อที่ยังไม่ได้พิสูจน์ไว้ใน [สถานะโครงงาน](docs/PROJECT_STATUS.md)

ไม่ใส่ `.env.local`, ฐานข้อมูล, session, backup/key, `.verification`, `node_modules` หรือ `.next` ลง Git ใช้เฉพาะข้อมูลสมมติ เครื่องอื่นจะได้ฐานและบัญชีจำลองของตนเอง

Demo SQLite รุ่นเดิมและคำสั่ง `seed:reset` อยู่ใน [เอกสารประวัติ](docs/archive/sqlite-demo.md) ไม่ใช้คำสั่งเหล่านั้นติดตั้ง Full System นี้
