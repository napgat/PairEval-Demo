# PairEval

ต้นแบบโครงงานนักศึกษาสำหรับประเมินผลงานแบบเปรียบเทียบเป็นคู่ อาจารย์จัดห้องเรียนและงานประเมิน นักศึกษาประเมินกลุ่ม/รายบุคคล แล้วดูคะแนนและขอทบทวนผลได้

**รุ่นปัจจุบัน: Full System ตาม PRD v2.0 สำหรับทดลองบนเครื่อง ด้วยข้อมูลสังเคราะห์** ไม่ใช่ระบบบันทึกคะแนนจริง ความพร้อมต้นแบบประมาณ **95%** ตามเกณฑ์ส่งมอบใน [สถานะโครงงาน](docs/PROJECT_STATUS.md) เพื่อนส่งผลทดลองแล้ว แก้ 2 ปัญหาผ่าน local และรอเพื่อนตรวจซ้ำตาม [บันทึก 17 ต.ค.](docs/full-system/peer-feedback-2026-10-17.md)

## เพื่อนเริ่มตรงนี้

**เพื่อนที่เคยติดตั้งแล้ว:** ใช้ [รายการตรวจซ้ำรุ่นล่าสุด](docs/PEER_RETEST.md) เพื่ออัปเดต main โดยเก็บข้อมูลเดิม รุ่นรูประฆังเริ่มที่ commit `643955f` ไม่ต้องล้างฐานหรือลง migration ใหม่

จุดที่ให้ลองซ้ำจากรายงานของเพื่อน:

- **กำหนดส่งรายบุคคลบันทึกแล้วเด้งกลับ:** งานที่เปิดใช้ด้านนี้ต้องบันทึกแล้ววันคงอยู่หลัง refresh; งานคะแนนรายบุคคล 0 จะปิดช่องพร้อมคำอธิบาย
- **ปิดอุทธรณ์ระหว่างทบทวนคะแนน:** หลัง Reopen/ปรับคะแนน ต้องยืนยัน Final ใหม่ก่อนตอบปิดคำขอ แล้วนักศึกษาต้องเห็นผลฉบับใหม่

เพิ่มฟอร์ม **ทีมผู้สอน** แล้ว: Owner เปิดรายชื่อและกลุ่มเพื่อเพิ่ม–ถอด Co-teacher/TA ด้วยอีเมลบัญชีที่มีอยู่ ดู [วิธีลองและผลตรวจ](docs/full-system/staff-management-2026-10-17.md)

การแจ้งเตือนอยู่ที่ **รูประฆังบน navbar** เปิดได้จากทุกหน้าใน Full System พร้อมจำนวนยังไม่อ่านและปุ่มอ่านทั้งหมด ดู [พฤติกรรมและผลทดสอบ](docs/testing/NOTIFICATION_BELL_2026-10-17.md)

ปรับเวลาใน **ประวัติการทำรายการและเวลาอัปเดตคะแนน** ให้ใช้เขตเวลาของห้อง พร้อมชื่อเขตเวลาบนจอแล้ว ดู [ผลตรวจเวลา 19 ต.ค.](docs/testing/AUDIT_TIMEZONE_2026-10-19.md) และใช้ [สคริปต์ Demo แบบอ่าน/กด/ชี้ตาม](docs/DEMO_SCRIPT_TH.md) เพื่อซ้อมนำเสนอ

รีโปเป็น **Private** เจ้าของต้องให้สิทธิ์บัญชี GitHub ของเพื่อนก่อน clone หรือส่ง source ZIP ของ main ให้โดยตรง ไม่ส่ง token/รหัสผ่านของเจ้าของให้เพื่อน

ทดสอบขั้นตอนติดตั้งบน **Windows x64 + Node.js 24** ใช้โฟลเดอร์ชื่อภาษาอังกฤษ เช่น `C:\PairEvalDemo` และอินเทอร์เน็ตสำหรับดาวน์โหลดครั้งแรก ยังไม่ได้ยืนยันขั้นตอนเปิด–ปิดบน macOS/Linux

```powershell
git clone https://github.com/napgat/PairEval-Demo.git C:\PairEvalDemo
cd C:\PairEvalDemo
npm ci
npm run build
.\Open-PairEval-Demo.cmd
```

## งานตัวอย่าง

- ห้องสาธิตมีนักศึกษา 16 คนใน 4 กลุ่ม พร้อม Owner, Co-teacher และ TA
- งานหลักเปิดรับ 7 วันนับจากเตรียมครั้งแรก ใช้ลอง Group/Individual, ร่าง, ส่งซ้ำ, คะแนนระหว่างดำเนินงาน และรายงาน
- เตรียมงาน Final/อุทธรณ์แยกได้ด้วย `npm run demo:prepare-final` **หลังเปิดบริการแล้ว** รอ deadline 5 นาทีจริงก่อนยืนยันคะแนน ดูขั้นตอนในคู่มือทดสอบ

เปิดสาธิตครั้งละหนึ่งโฟลเดอร์ ใช้ port 3101, 3103 และ 55432 เฉพาะเครื่องตนเอง หยุดด้วย:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop-PairEval-Demo.ps1
```

```powershell
npx playwright install chromium

```

ผลตรวจ local รุ่นรูประฆัง: **unit tests 107/107, ตรวจแจ้งเตือน 17 จุด และ GUI regression 24 สถานะผ่าน** พร้อม typecheck/lint/build; รวมจอเล็ก คีย์บอร์ด และซูมจริง 200% ดู [ผลตรวจแจ้งเตือน](docs/testing/NOTIFICATION_BELL_2026-10-17.md)

ผล [UI 98/98](docs/testing/MANUAL_UI_98_RESULTS_2026-10-17.md) เป็นหลักฐานก่อนเปลี่ยน navbar คู่มือปัจจุบันเพิ่มเป็น **100 กรณี** โดยยังไม่อ้างว่ารันใหม่ครบทั้ง 100 ส่วนสูตร/CSV/XLSX อิสระ 16 คนและ audit/restore ดู [รายงาน Backend](docs/testing/FULL_SYSTEM_BACKEND_UI_2026-10-17.md) ยังรอเพื่อนตรวจซ้ำบนเครื่องของตนเอง

ไม่ใส่ `.env.local`, ฐานข้อมูล, session, backup/key, `.verification`, `node_modules` หรือ `.next` ลง Git ใช้เฉพาะข้อมูลสมมติ เครื่องอื่นจะได้ฐานและบัญชีจำลองของตนเอง

Demo SQLite รุ่นเดิมและคำสั่ง `seed:reset` อยู่ใน [เอกสารประวัติ](docs/archive/sqlite-demo.md) ไม่ใช้คำสั่งเหล่านั้นติดตั้ง Full System นี้
